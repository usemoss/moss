# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.2] - 2026-11-18

### Changed

- The package metadata declares the BSD-2-Clause license, and the wheel and sdist ship `LICENSE`.
- Requires `moss` 1.1.1 or later.
- Supports Python 3.14.

## [0.0.1] - 2026-03-30

### Added

- Initial release of `elevenlabs-moss` integration.
- `MossClientTool` for registering Moss semantic search as an ElevenLabs client tool.
- Example `moss-elevenlabs-demo.py` demonstrating tool registration.
